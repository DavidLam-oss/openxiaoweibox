## 那个让我头疼的字幕问题

先简单回顾一下。

官方 Obsidian Web Clipper 有个很棒的 YouTube 阅读模式，打开视频页面点扩展图标，左边章节大纲、中间播放器、下方带时间戳的完整字幕，还能自动滚动和高亮当前行。

浏览体验好到什么程度呢？好到你几乎忘了它还有一个致命的问题，剪下来的字幕是空的。

不管怎么设置，字幕内容就是没有被当成页面内容抓取到 Obsidian 里。我试了各种组合，甚至怀疑是我操作不对，结果社区里也有人遇到同样的问题。

这个功能上的缺失，就是整件事的起点。

![Obsidian 入门49：从官方剪藏到社区增强，飞书/B站/公众号都能剪了 - 配图 2](/images/posts/Obsidian%20%E5%85%A5%E9%97%A849%EF%BC%9A%E4%BB%8E%E5%AE%98%E6%96%B9%E5%89%AA%E8%97%8F%E5%88%B0%E7%A4%BE%E5%8C%BA%E5%A2%9E%E5%BC%BA%EF%BC%8C%E9%A3%9E%E4%B9%A6B%E7%AB%99%E5%85%AC%E4%BC%97%E5%8F%B7%E9%83%BD%E8%83%BD%E5%89%AA%E4%BA%86/20260518232256232.webp)

## 群友推荐的这个版本

obsidian-clipper-cn 是官方剪藏插件 Obsidian Web Clipper 的一个 Fork。它保留了官方的所有功能，通用网页剪藏、高亮标注、模板系统、AI 解释器都在，然后在上面叠加了三层针对中文平台的增强。

我一个个说。

这个插件的整个功能跟官方的 Obsidian 插件是一模一样的，设置设置界面都是一模一样。

### Youtube 视频

点开阅读模式之后，可以在一个干净的阅读网页上面观看 YouTube 视频。有字幕的视频，其对应的字幕会呈现在下方。

![Obsidian 入门49：从官方剪藏到社区增强，飞书/B站/公众号都能剪了 - 截图 3](/images/posts/Obsidian%20%E5%85%A5%E9%97%A849%EF%BC%9A%E4%BB%8E%E5%AE%98%E6%96%B9%E5%89%AA%E8%97%8F%E5%88%B0%E7%A4%BE%E5%8C%BA%E5%A2%9E%E5%BC%BA%EF%BC%8C%E9%A3%9E%E4%B9%A6B%E7%AB%99%E5%85%AC%E4%BC%97%E5%8F%B7%E9%83%BD%E8%83%BD%E5%89%AA%E4%BA%86/CleanShot%25202026-05-18%2520at%252022.35.14.webp)

功能特点如下：

1. 点击对应时间戳的字幕，视频会跳转到相应的时间点
2. 按照自然速度观看视频时，下方的字幕会自然跟随滚动到对应的时间点位置
3. 当你往下滚动查看字幕时，上方的视频会置顶吸附在顶部

和官方插件上碰到的问题不一样的是，当我点击剪藏的时候，它会将视频的链接还有字幕，跟随时间戳一起剪藏到 Obsidian 里面来。

![Obsidian 入门49：从官方剪藏到社区增强，飞书/B站/公众号都能剪了 - 截图 4](/images/posts/Obsidian%20%E5%85%A5%E9%97%A849%EF%BC%9A%E4%BB%8E%E5%AE%98%E6%96%B9%E5%89%AA%E8%97%8F%E5%88%B0%E7%A4%BE%E5%8C%BA%E5%A2%9E%E5%BC%BA%EF%BC%8C%E9%A3%9E%E4%B9%A6B%E7%AB%99%E5%85%AC%E4%BC%97%E5%8F%B7%E9%83%BD%E8%83%BD%E5%89%AA%E4%BA%86/CleanShot%25202026-05-18%2520at%252022.40.11.webp)

### B 站视频：把 YouTube 那套体验搬过来了

更加适配国内宝宝体质的是，官方版在 YouTube 上有的那套功能，阅读模式、字幕提取、视频嵌入，这个 Fork 全给 B 站也做了一份。而且做得还挺细。

![Obsidian 入门49：从官方剪藏到社区增强，飞书/B站/公众号都能剪了 - 截图 5](/images/posts/Obsidian%20%E5%85%A5%E9%97%A849%EF%BC%9A%E4%BB%8E%E5%AE%98%E6%96%B9%E5%89%AA%E8%97%8F%E5%88%B0%E7%A4%BE%E5%8C%BA%E5%A2%9E%E5%BC%BA%EF%BC%8C%E9%A3%9E%E4%B9%A6B%E7%AB%99%E5%85%AC%E4%BC%97%E5%8F%B7%E9%83%BD%E8%83%BD%E5%89%AA%E4%BA%86/CleanShot%25202026-05-18%2520at%252022.47.36.webp)

- 提取视频简介、章节、字幕
- Reader Mode 里嵌入 Bilibili 播放器，可以置顶固定
- 点击字幕或章节的时间戳，视频直接跳转到对应时间
- 播放过程中字幕自动滚动，当前行高亮显示
- Chrome 和 Firefox 都支持

如果你经常在 B 站看各种教程和技术分享，这个功能意味着 B 站的视频内容也可以像网页一样被剪藏、被搜索、被引用。

我试了一个 50 分钟的教程视频，字幕全出来了，时间戳也能跳，跟之前在 YouTube 上的体验差不多。终于不用再在 B 站和 Obsidian 之间来回切了。

不过我最后测试了一下，将这个 B 站的视频剪藏到 Obsidian 里面来，发现字幕这些都过来了，但是视频的链接没有置顶放在笔记的顶部。

### 飞书文档：不走 DOM 解析，走 API

飞书文档在官方版本的剪藏插件里用的是通用 DOM 解析，但因为飞书的内容是动态渲染的，经常提取不全，要么漏了表格，要么图片抓不到。

这个 Fork 换了个思路，直接接入飞书开放平台的 API，走结构化接口拿数据。

- 获取文档所有块内容，文字、标题、列表、代码块、表格、引用，一个不落（大部分文档都能搞定了）
- 图片通过飞书 Web API 下载，只要你浏览器里能打开，剪藏时就能正常显示
- 飞书知识库（/wiki/）和普通文档（/docx/）都支持

配置需要去飞书开放平台搞个自建应用，开两个权限，填两个密钥就行。第一次配大概十分钟。密钥只存在本地浏览器，不会上传。

![Obsidian 入门49：从官方剪藏到社区增强，飞书/B站/公众号都能剪了 - 截图 6](/images/posts/Obsidian%20%E5%85%A5%E9%97%A849%EF%BC%9A%E4%BB%8E%E5%AE%98%E6%96%B9%E5%89%AA%E8%97%8F%E5%88%B0%E7%A4%BE%E5%8C%BA%E5%A2%9E%E5%BC%BA%EF%BC%8C%E9%A3%9E%E4%B9%A6B%E7%AB%99%E5%85%AC%E4%BC%97%E5%8F%B7%E9%83%BD%E8%83%BD%E5%89%AA%E4%BA%86/CleanShot%25202026-05-18%2520at%252022.53.23.webp)

### 公众号文章：修了最烦人的图片问题

写 Obsidian 系列这一年多，被问到最多的一个问题是：「为什么剪藏到 Obsidian 的公众号文章，图片过段时间就没了？」（[Obsidian 入门48：为什么剪藏到 Obsidian 的文章，图片过段时间就没了？](/blog/Obsidian%20%E5%85%A5%E9%97%A848%EF%BC%9A%E4%B8%BA%E4%BB%80%E4%B9%88%E5%89%AA%E8%97%8F%E5%88%B0%20Obsidian%20%E7%9A%84%E6%96%87%E7%AB%A0%EF%BC%8C%E5%9B%BE%E7%89%87%E8%BF%87%E6%AE%B5%E6%97%B6%E9%97%B4%E5%B0%B1%E6%B2%A1%E4%BA%86%EF%BC%9F)）

微信公众号文章的图片，是公认的老大难。官方版 Web Clipper 用的是通用正文提取器，遇到微信的懒加载图片和动态正文结构，常见问题就是只抓到首图，后面的图全裂。

这个 Fork 做了几件事。

- 优先使用微信公众号的原始正文容器 `#js_content`，避免通用提取器把后续内容裁掉
- 自动识别 `data-src`、`data-original`、`data-lazy-src` 等懒加载属性，补全为标准 `src`
- 保留正文中的多张 `mmbiz.qpic.cn` 图片，不再只抓第一张
- 浏览器扩展、CLI 和 API，无论哪种入口输出都一致

如果你剪藏公众号文章比较多，这一项升级应该是最能感知到的变化。

我用它去试着剪藏了我昨天发布的那篇文章。

我发现完全不需要自己去疯狂滚动鼠标，一直滚动到页面底部再去点剪藏按钮。现在你只需要打开链接，直接点击插件图标去剪藏，就能把整篇文章的图片都一次性拿过来了。

![Obsidian 入门49：从官方剪藏到社区增强，飞书/B站/公众号都能剪了 - 截图 7](/images/posts/Obsidian%20%E5%85%A5%E9%97%A849%EF%BC%9A%E4%BB%8E%E5%AE%98%E6%96%B9%E5%89%AA%E8%97%8F%E5%88%B0%E7%A4%BE%E5%8C%BA%E5%A2%9E%E5%BC%BA%EF%BC%8C%E9%A3%9E%E4%B9%A6B%E7%AB%99%E5%85%AC%E4%BC%97%E5%8F%B7%E9%83%BD%E8%83%BD%E5%89%AA%E4%BA%86/CleanShot%25202026-05-18%2520at%252022.55.27.webp)

## 装上就能用

方向对了，用起来才知道是不是真的好。

安装倒是没什么门槛。去项目 Releases 页面下载对应浏览器的压缩包，解压。

![Obsidian 入门49：从官方剪藏到社区增强，飞书/B站/公众号都能剪了 - 截图 8](/images/posts/Obsidian%20%E5%85%A5%E9%97%A849%EF%BC%9A%E4%BB%8E%E5%AE%98%E6%96%B9%E5%89%AA%E8%97%8F%E5%88%B0%E7%A4%BE%E5%8C%BA%E5%A2%9E%E5%BC%BA%EF%BC%8C%E9%A3%9E%E4%B9%A6B%E7%AB%99%E5%85%AC%E4%BC%97%E5%8F%B7%E9%83%BD%E8%83%BD%E5%89%AA%E4%BA%86/CleanShot%25202026-05-18%2520at%252022.58.40.webp)

然后在插件管理页面，按照下图的知识先打开开发者模式，接着点击左上角的按钮加载解压后的文件夹就行了。

## 谁适合这个增强版

如果你有以下情况之一，值得试一试。

- 经常在 B 站看教程，想把视频字幕和笔记一起存进 Obsidian
- 公司或团队用飞书，需要把飞书文档剪藏到个人知识库
- 公众号文章是你的主要信息来源，受够了剪下来图片全裂

如果你只是偶尔剪藏一下网页，官方版已经够用，这个增强版不会改变你已有的使用习惯，它只是在你需要用到那些功能的时候，发现它们都已经在了。

## 回到那个字幕问题

所以，YouTube 字幕现在能剪了吗？

能了。

装好之后试了一下，同一个视频，之前剪下来字幕区是空的，现在带时间戳的完整字幕一条不少地进了 Obsidian。跟官方版 YouTube 阅读模式的浏览体验一样好，多了一个「这次真的剪下来了」的结局。

这篇文章写在入门44的 6 天后。从「求社区支招」到「找到了」的时间，比我预想的短很多。

感谢那位群友。
