## 进入 YouTube 剪藏模式

随便打开一个有字幕的 YouTube 视频，点 Web Clipper 图标。

页面会重新排版，左边是章节大纲（视频本身有章节才会显示），中间是播放器，下方是带时间戳的完整字幕。

> [!tip] 怎么进入
> 点 Web Clipper 图标后，找面板里那个「摊开书本」的图案，点一下就进去了。跟普通网页剪藏的入口不一样，别找错了。

在阅读模式页面中，视频下方有三个开关，默认都是开的，我一个一个说。

![Obsidian 入门44：YouTube 视频字幕剪藏实战——能看但剪不下来 - 截图 2](/images/posts/Obsidian%20%E5%85%A5%E9%97%A844%EF%BC%9AYouTube%20%E8%A7%86%E9%A2%91%E5%AD%97%E5%B9%95%E5%89%AA%E8%97%8F%E5%AE%9E%E6%88%98%E2%80%94%E2%80%94%E8%83%BD%E7%9C%8B%E4%BD%86%E5%89%AA%E4%B8%8D%E4%B8%8B%E6%9D%A5/CleanShot%25202026-05-10%2520at%252016.24.56.webp)

第一个叫「固定播放器」。开了之后，你往下翻字幕的时候，播放器会钉在屏幕顶部，不会被翻走。这个设计挺贴心的，因为以前看 YouTube 字幕，翻着翻着视频就看不见了，得滚回去。

第二个叫「自动滚动」。视频播到哪里，字幕区域就自动滚到哪里，当前这句始终在中间。不用手动跟，也不用暂停反复找。

第三个叫「高亮当前行」。正在播的那行字幕会高亮显示，扫一眼就知道现在讲到哪。

三个同时打开的体验是，上面看画面，下面跟着滚动的字幕走，想跳哪儿点哪行字幕就行。不用来回拖进度条，也不用暂停反复找。

> [!note] 视频没有下载到本地
> Web Clipper 只是把 YouTube 页面重新排版了，视频仍然是在线播放。它做的事情是让视频内容第一次变得「可浏览」，字幕变成了结构化的文本。

![流畅的阅读体验](/images/posts/Obsidian%20%E5%85%A5%E9%97%A844%EF%BC%9AYouTube%20%E8%A7%86%E9%A2%91%E5%AD%97%E5%B9%95%E5%89%AA%E8%97%8F%E5%AE%9E%E6%88%98%E2%80%94%E2%80%94%E8%83%BD%E7%9C%8B%E4%BD%86%E5%89%AA%E4%B8%8D%E4%B8%8B%E6%9D%A5/Project_Obsidian_%25E5%2585%25A5%25E9%2597%25A844_Web_Clipper%25E8%25A7%2586%25E9%25A2%2591%25E5%2589%25AA%25E8%2597%258F_illustration-02_c5ca78a3_20260511.webp)

## 划重点，下次打开还在

在阅读模式里选中字幕文字，可以直接高亮，跟在网页文章上划重点一样。高亮信息存在浏览器本地，关掉标签页重新打开还在，只要你是同一台电脑同一个浏览器就行。

等你剪藏的时候，这些高亮理论上会一起进 Obsidian，时间戳和视频链接也会带上，但前提是你能把字幕成功剪下来。这就引出了下面这个问题。

---

## 我踩的坑：字幕看得到，剪不下来

功能看到这里，你可能会想，界面这么好用，那把字幕剪进 Obsidian 总没问题吧？

我一开始也这么想。结果折腾了一整天，试了所有能想到的方法，都没搞定。

![四处碰壁](/images/posts/Obsidian%20%E5%85%A5%E9%97%A844%EF%BC%9AYouTube%20%E8%A7%86%E9%A2%91%E5%AD%97%E5%B9%95%E5%89%AA%E8%97%8F%E5%AE%9E%E6%88%98%E2%80%94%E2%80%94%E8%83%BD%E7%9C%8B%E4%BD%86%E5%89%AA%E4%B8%8D%E4%B8%8B%E6%9D%A5/Project_Obsidian_%25E5%2585%25A5%25E9%2597%25A844_Web_Clipper%25E8%25A7%2586%25E9%25A2%2591%25E5%2589%25AA%25E8%2597%258F_illustration-03_4999565a_20260511.webp)

### 我试过的方法

**1. 直接点「添加到 Obsidian」**

剪下来的笔记只有标题、频道、URL，字幕部分一片空白。

**2. 等字幕全部加载完再剪藏**

我试过把页面拉到最底部，确认字幕全部渲染出来了，再点添加。结果一样空的。

**3. 导入官方 YouTube 模板**

去 Obsidian 官方 GitHub 仓库（kepano/clipper-templates）把 YouTube 模板的 JSON 下载下来，导入到 Web Clipper 设置里。结果依然抓不到字幕。

后来我仔细看了官方模板的内容，发现它本身**就没有用 `{{transcript}}` 变量**，只存了标题、作者、日期、URL、缩略图这几个字段。即便功能正常，那个模板也不会帮你存字幕。

所以我又自己在模板内容里手动加上了 `{{transcript}}`，然后再剪藏。结果出来的笔记里，`{{transcript}}` 那一栏依然是空的。

**4. 退出阅读模式再剪藏**

回到 YouTube 普通页面，字幕也显示着，剪藏依然抓不到。

### 问题出在哪

这里有一个矛盾的地方。

我确确实实看到过有人录视频演示，打开 Web Clipper 的 YouTube 阅读模式，点一下添加，字幕就跟着进了 Obsidian，整个过程非常顺畅。说明这个功能本身是能工作的。

但在我这边，所有方法都试过了就是不行。所以我现在的猜测是，**YouTube 最近可能有过改版或更新**，改变了字幕在前端的加载方式，导致 Web Clipper 获取字幕的那条路径被打破了。那些演示视频可能是改版之前录的，那时候还能正常工作。

当然这只是猜测，具体的原因还需要进一步确认。

## 阅读模式本身还是值得一试

话说回来，即使暂时剪藏不了字幕，Web Clipper 的 YouTube 阅读模式本身已经是一个很好的浏览体验。可滚动字幕、自动跟随播放进度、高亮标注，这些功能让视频第一次变得可以「浏览」。

你仍然可以开着阅读模式看完视频，手动把关键内容复制到 Obsidian。虽然多了一步操作，但比之前反复拖进度条找内容还是方便多了。

至于剪藏字幕的事，等找到稳定的方案再来补上。
