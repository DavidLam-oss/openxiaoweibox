我想在 Obsidian 里免费用 AI。

不想配置 API key，不想买额度，不想包月。就想打开 Obsidian，写着写着有问题了，顺手问一下 AI，问完继续写。

其实很简单。一个插件就能搞定。

---

## 先说痛点

用 Obsidian 写东西，写着写着需要查资料，于是切到浏览器，查完再复制回来。

现在 AI 用得越来越多，这个问题更明显了。豆包、Kimi、Deepseek……每次都要开浏览器，开网页，来回切换。

当然，Obsidian 也有各种 AI 插件。但基本都要配置 API key。

API key 意味着什么？**要钱**。要么买额度，要么包月。

但我作为一个普通人，就想用免费的。效果不用多好，日常够用就行。

---

## 解决方案：Custom Frames

这个插件叫 **Custom Frames**，原理很简单：把网页直接嵌进 Obsidian。

你常用的 AI 网站——豆包、Kimi、Deepseek——都可以嵌进来。登录账号后，就能在 Obsidian 里正常使用了。

免费，不用配置 API，不用懂代码。

---

## 怎么装？三步搞定

不会英文也没关系，照着截图点就行。

### 第一步：安装插件

1. 打开 Obsidian 设置
2. 进入 Community Plugins
3. 点击 Browse
4. 搜索 Custom Frames，点击安装
5. 点击 Enable 启用

![插件安装界面](/images/posts/%E4%B8%8D%E8%8A%B1%E4%B8%80%E5%88%86%E9%92%B1%EF%BC%8C%E8%AE%A9%E8%B1%86%E5%8C%85%E3%80%81Kimi%E3%80%81Deepseek%E4%BD%8F%E8%BF%9BObsidian/20260117231323123.webp)

### 第二步：添加 AI 网站

安装后，在插件设置里可以看到一些内置网站（Google、Twitter 之类的）。

![插件设置界面](/images/posts/%E4%B8%8D%E8%8A%B1%E4%B8%80%E5%88%86%E9%92%B1%EF%BC%8C%E8%AE%A9%E8%B1%86%E5%8C%85%E3%80%81Kimi%E3%80%81Deepseek%E4%BD%8F%E8%BF%9BObsidian/20260117231436517.webp)

我们要添加自己的。以豆包为例：

1. 点击 Add Frame
2. 填入豆包网址：`https://www.doubao.com`
3. 取个名字（比如 doubao），选个图标

![添加豆包](/images/posts/%E4%B8%8D%E8%8A%B1%E4%B8%80%E5%88%86%E9%92%B1%EF%BC%8C%E8%AE%A9%E8%B1%86%E5%8C%85%E3%80%81Kimi%E3%80%81Deepseek%E4%BD%8F%E8%BF%9BObsidian/20260117231625172.webp)

其他保持默认，保存就行。

### 第三步：开始使用

Mac 按 Command + P，Windows 按 Ctrl + P，调出命令面板，输入刚才取的名字 doubao。

![命令面板](/images/posts/%E4%B8%8D%E8%8A%B1%E4%B8%80%E5%88%86%E9%92%B1%EF%BC%8C%E8%AE%A9%E8%B1%86%E5%8C%85%E3%80%81Kimi%E3%80%81Deepseek%E4%BD%8F%E8%BF%9BObsidian/20260117231831318.webp)

点击后，豆包就会在侧边栏打开。登录账号，就可以边写笔记边跟 AI 聊天了。

![使用效果](/images/posts/%E4%B8%8D%E8%8A%B1%E4%B8%80%E5%88%86%E9%92%B1%EF%BC%8C%E8%AE%A9%E8%B1%86%E5%8C%85%E3%80%81Kimi%E3%80%81Deepseek%E4%BD%8F%E8%BF%9BObsidian/20260117231936953.webp)

## 豆包、Kimi、Deepseek，我该用哪个？

既然都能嵌进来，那该用哪个？

我的建议是：**都装上，按场景切换**。它们各有所长。

### 豆包：生图小能手

写公众号的时候，我经常让豆包帮我生成封面和配图。跟它聊天也挺顺的，日常问答、头脑风暴都能用。

### Kimi：长文处理王

我用它来总结论文、整理长笔记。有一次把一整篇万字长文丢给它，它居然真的看完了，还给我列了个提纲。省时间。

### Deepseek：推理担当

脑子比较清楚，代码也写得不错。遇到技术问题或者需要分析复杂逻辑的时候，我会优先问它。

### 小结

| 平台         | 核心优势           | 适合场景           |
| ------------ | ------------------ | ------------------ |
| **豆包**     | 生图能力强、聊天顺 | 生成配图、日常问答 |
| **Kimi**     | 长文处理突出       | 读论文、总结文档   |
| **Deepseek** | 逻辑硬、代码强     | 技术问题、写代码   |

它们都是免费的，额度也够日常使用。

---

## 一些小提示

1. **桌面端体验最好**。移动端的 Obsidian 对这个插件支持有限，部分网站可能登录不了。

2. **可以同时嵌入多个**。左边豆包生图，右边 Kimi 总结，配合起来效率更高。

3. **账号密码只在你自己电脑上，放心**。不经过任何第三方。

4. **ChatGPT 网页版可能用不了**。OpenAI 有安全限制，优先试国产 AI。
