发现自己在平台都有账号、都有历史聊天记录，

你是否有困扰，在一些 AI 工具中，总是要有自己的 API key 才能畅快的享用工具提供的服务？

但是也困扰，我们普通人去哪里搞属于自己的API key 呢？

其实很简单，只需要登录各大厂的API开放平台，注册登录之后就可以创建API key。

例如 Deepseek API 开放平台

例如 Kimi

此时大家可能会有疑问，那我要用一家的 API 就要在一家开个账户接着创建 API。那么我如果要使用5家厂商的模型，我岂不是在 5 个平台开账号创建 API。

是的，某种程度上与现在的现象：要看优酷、腾讯、爱奇艺、芒果 TV的独播视频，你就得下载这么多个 APP、开这么多的会员是非常类似的。

你可能会问，是否有某个聚合平台可以把这些厂商的模型都放在一起，我只需要开一家的账号，创建一个 API key 就可以调用大部分甚至所有的模型呢？

答案是：有的。

国内的”硅基流动“就是这样一家平台：聚合了国内绝大部分的模型，包括对话、生图、视频、语音等。在硅基流动创建 API 就可以一个 key 通享这所有的模型。
![AI 时代，普通人怎么拥有自己的 API - 配图 3](/images/posts/202510292256621.webp)
