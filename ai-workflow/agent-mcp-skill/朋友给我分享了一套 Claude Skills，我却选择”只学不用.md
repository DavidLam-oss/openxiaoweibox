一个朋友分享了一套 Claude Skills，叫 vibe-writing。

专门用来写公众号文章，降 AI 味、过检测、三遍审校。

说实话，我有点心动。

翻了一遍他的文档，发现确实有干货：必删套话清单、书面词替换表、开头结尾模式。

**但我没有直接用。**

> 补充一下背景：Claude Skills 是 2025 年 10 月 Anthropic 推出的功能，本质上是一套"规则文件夹"，Claude 会在识别到相关任务时自动调用。而 vibe-writing 是用这个格式做的一套中文写作 Skills。

---

## 为什么不直接用？

不是不好，是"不适合我"。

### 第一，我已经有一套成熟的流程了

我的"大卫写作天团"跑了快两个月了。9 个 AI 角色，4 个阶段，4 个确认点。

如果你感兴趣，可以看看我之前写的两篇介绍：[AI 写的文章没有灵魂？那是你没把自己当成"甲方"](/blog/AI 写的文章没有灵魂？那是你没把自己当成“甲方”) 和 [用 AI 审阅 AI：我的写作天团升级记](/blog/%E7%94%A8%20AI%20%E5%AE%A1%E9%98%85%20AI%EF%BC%9A%E6%88%91%E7%9A%84%E5%86%99%E4%BD%9C%E5%A4%A9%E5%9B%A2%E5%8D%87%E7%BA%A7%E8%AE%B0)。

从阿文转写、呼延审结构、冰清润色、罗永浩挑刺、韩梅梅试读，到马科婷包装、张艺谋配图、鲁迅归档。

![朋友给我分享了一套 Claude Skills，我却选择只学不用 - 配图 1](/images/posts/%E6%9C%8B%E5%8F%8B%E7%BB%99%E6%88%91%E5%88%86%E4%BA%AB%E4%BA%86%E4%B8%80%E5%A5%97%20Claude%20Skills%EF%BC%8C%E6%88%91%E5%8D%B4%E9%80%89%E6%8B%A9%22%E5%8F%AA%E5%AD%A6%E4%B8%8D%E7%94%A8%22/20260109173146111.webp)

整个流程已经磨合得比较顺了。

如果要把它改造成 Claude Skills 的格式，等于从头重写一遍。时间成本不划算。

### 第二，我的主力工具不是 Claude Code

Claude Skills 是 Claude 平台的专属功能。

它本质上是一个"文件夹"，包含指令和脚本，Claude 在识别到相关任务时会自动调用。

听起来很智能，但问题是：我日常用的是 Google Antigravity（就是 Gemini 的 coding agent），不是 Claude。

如果我把所有流程都绑定在 Claude 上，等于给自己上了一道锁。

哪天 Gemini 又出了什么新功能，或者出了新的 Agent 工具，我就得重新迁移。

**保持工具无关性，反而更灵活。**

当然，如果后续 Google Antigravity 也支持 Skills 了，那么我肯定要将它改造的。

### 第三，Skills 和 Workflow 的本质区别

| 维度     | Claude Skills   | 我的 Workflow  |
| -------- | --------------- | -------------- |
| 绑定平台 | Claude 专属     | 工具无关       |
| 存储形式 | 特定文件结构    | 普通 Markdown  |
| 触发方式 | Claude 自动识别 | 手动调用       |
| 可迁移性 | 无法迁移        | 可用于任何 LLM |

所以我的选择是：**不用他的 Skills，但可以学他的思路。**

---

## 我怎么做？

我花了半天时间，把 vibe-writing 里有价值的东西融合进我现有的流程。

![朋友给我分享了一套 Claude Skills，我却选择只学不用 - 配图 2](/images/posts/%E6%9C%8B%E5%8F%8B%E7%BB%99%E6%88%91%E5%88%86%E4%BA%AB%E4%BA%86%E4%B8%80%E5%A5%97%20Claude%20Skills%EF%BC%8C%E6%88%91%E5%8D%B4%E9%80%89%E6%8B%A9%22%E5%8F%AA%E5%AD%A6%E4%B8%8D%E7%94%A8%22/20260109173314228.webp)

### 1. 降 AI 味检查清单

这是 vibe-writing 最有价值的部分。

我把它提炼成一份结构化的清单，加到冰清也就是文档撰写的主力角色的规则文件里：

- 必删套话：「在当今时代」「综上所述」「值得注意的是」
- 书面词替换：「进行操作」→「操作一下」，「显著提升」→「提升不少」
- 句式检查：超过 30 字的句子必须拆短
- 开头检查：禁止「在当今时代」式的万能开头

然后，我让罗永浩在阶段三增加一个「降 AI 味审校」环节。

他本来就负责挑刺，现在多了一个挑刺维度。

### 2. 开头结尾模式

vibe-writing 给了三种开头模式：

- 真实场景引入：「两个小时做的网站，拿了 5000 美金特等奖。」
- 个人经历引入：「我之前在公司做产品经理的时候...」
- 直接提问引入：「产品经理能写代码吗？」

三种结尾模式：

- 个人思考：「这很重要。」
- 行动建议：「先做起来，边做边学。」
- 开放式：「这是我的经历。你的呢？」

我把这些示例加到冰清的规则里，让她在写作时有明确的参照。

### 3. 新增季羡林研究员

这是我之前一直缺的环节。

以前所有素材都是我自己提供，AI 只负责加工。

现在我加了一个"季羡林"角色，专门负责外部调研：

- 验证数据准确性
- 补充背景信息
- 找类似案例
- 寻找权威来源
- 补充边界和反例

取名季羡林，是因为他的人设是"温和、治学严谨、博古通今"。

### 4. 韩梅梅视角调整

以前韩梅梅的人设是"公众号关注者"，粉丝视角。

但我现在粉丝量只有 200 多，主要靠算法推荐获取流量。

所以我把她的视角从"粉丝"调整为"信息流中被推荐来的陌生路人"。

她现在的任务是：

- 3 秒钩子测试：看到标题封面摘要，会不会点进去？
- 开头停留测试：前 3 句话能不能让我停下来？

这比原来的"完读率测试"更符合我的实际需求。

### 5. 标题摘要策略升级

呼延雷锋和马科婷的职责也调整了。

标题：从「准确描述内容」转向「激发点击欲」。

摘要：从「概括文章」转向「制造期待」。

---

工具是流动的，方法论是沉淀的。

Claude Skills 是个好东西，但它是 Claude 生态的一部分。

我选择把有价值的思路提取出来，融合到我自己的流程里。

这样，不管将来用什么工具，这套方法论都能继续用。

与其追最新的 Skills，不如把自己的流程打磨到位。

保持开放，但不盲从。
