## 对比：我的选择逻辑

我也考虑过使用微信输入法来存储 Prompt。但微信输入法的快捷短语功能最高只能存储1000 个汉字或 3000 个英文字符，应对普通长度的常用句子是够用了。但我们的魔法 prompt 超过 2000 字，对于微信输入法来说就有些捉襟见肘了。

### Raycast Snippets储超长指令

**Raycast Snippets** 专为超长、复杂的代码/指令/Prompt而生。像我们那种包含了大量 HTML/CSS 规范的方案二 prompt，Raycast 就能轻松存储和调用，无需担心字符限制，确保我们能在任何 AI 界面都保持一致的高效。

### Snippets 的“全局调用”爽感

我选择 Raycast Snippets 作为 Prompt 的“武器库”的另外一个原因是，因为它和普通的输入法快捷短语最大的区别，也是它让我感到最“爽”的 Aha-moment，就是它能**支持全局调用**。

这意味着，无论你是在 **Claude** 的网页对话框、**Gemini** 的开发界面，还是在你的 **Obsidian** 笔记中，只要你输入自定义的“暗号”，这个超长的 Prompt 就会像魔法一样瞬间出现。

## Snippets 是什么？

我们根据[Raycast Snippet 入门指南：让输入变得更简单](/blog/Raycast%20Snippet%20%E5%85%A5%E9%97%A8%E6%8C%87%E5%8D%97%EF%BC%9A%E8%AE%A9%E8%BE%93%E5%85%A5%E5%8F%98%E5%BE%97%E6%9B%B4%E7%AE%80%E5%8D%95)再来复习一下 Snnippets是什么。

你可以把 Snippets 理解为一个专业级的、支持变量的超长文本储存库。它拥有普通快捷短语难以比拟的优势：

1. **超长文本支持：** 轻松存储我们那种动辄几百字的复杂指令，无需担心字符限制。
2. **全局秒速调用：** 只要设定一个简短的关键词（如 `!html`），在 Mac 上的任何输入框都能瞬间触发。
3. **支持变量：** 可以自动插入当前日期、时间、甚至剪贴板内容等变量，让你的 Prompt 更加智能化和自动化。

## 场景应用：将“黑科技”武装到 Raycast

现在，让我们把上一篇文章中最耗时的两个“魔法 Prompt”变成可以一秒调用的 Snippets。

### 案例：存储“HTML 创意总监 Prompt”

这个 Prompt 负责帮你生成专业级的可视化配图，非常长，非常适合用 Snippets 存储。

**【操作演示】**

1. **打开 Raycast：** 按下你的 Raycast 快捷键 **`Cmd + Space`**。
2. **创建 Snippet：** 在搜索框中输入 **`Create Snippet`** 并打开功能。
3. **配置参数：**
   - **Name (名称)：** 输入 **`HTML 创意总监 Prompt`**。
   - **Snippet (内容)：** 将超长 **HTML 生成 Prompt** 全文粘贴进去。
   - **Keyword (调用关键词)：** 这是关键！建议设置一个简单、不常用的组合，例如 **`!htmlpro`** 或 **`!html`**。

4. **保存：** 点击右下角的 **`Save Snippet`**。

当你下次需要配图时，只需在 AI 聊天框里输入 **`!html`**，你的“创意总监”需求文档就会瞬间出现，等待你粘贴文章内容。整个复制粘贴的繁琐过程被彻底消除。
