## 私有网盘后台

File Browser 简单说就是一个网页版的文件管理器。

装好之后，它就像是给你那台冷冰冰的服务器加了一个私有的网盘后台。打开手机浏览器，输入地址，登录，你就能像翻相册一样直接看到服务器里的文件夹。把手机里的配图直接上传，搞定。

![给你的 OpenClaw 装个「手机遥控器」，文件管理全搞定 - 配图 2](/images/posts/%E7%BB%99%E4%BD%A0%E7%9A%84%20OpenClaw%20%E8%A3%85%E4%B8%AA%E3%80%8C%E6%89%8B%E6%9C%BA%E9%81%A5%E6%8E%A7%E5%99%A8%E3%80%8D%EF%BC%8C%E6%96%87%E4%BB%B6%E7%AE%A1%E7%90%86%E5%85%A8%E6%90%9E%E5%AE%9A/%25E6%2589%258B%25E6%259C%25BA%25E8%25AE%25BF%25E9%2597%25AE%25E6%259C%258D%25E5%258A%25A1%25E5%2599%25A8%25E6%2596%2587%25E4%25BB%25B6_illustration-02_20260228.webp)

最省心的是不需要记 Linux 命令。把下面这段话复制下来，直接扔给你的 AI 助手（比如 OpenClaw）：

```text
帮我在服务器上安装 File Browser，要求：
1. 根目录设置为 /home/[你的用户名]
2. 监听地址 127.0.0.1，端口 8088
3. 配置为 systemd 服务，确保开机自启
4. 用 Caddy 做反向代理

如果我有域名：我的域名是 [你的域名]，帮我配置 HTTPS，并告诉我需要在 Cloudflare 怎么加解析。
如果没有域名：直接帮我开放 8088 端口，我用 IP:8088 访问。
```

AI 会像个熟练的技工，帮你搭好服务并配好开机自启。就算服务器重启，它也会在后台默默重新跑起来。

## 必做的「推门」动作

不过，在这个过程中，有一道「门」必须亲手推开：开防火墙。

云服务器默认只开了一扇供远程登录的窄门（22 端口），其他地方是被墙封死的。如果不放行端口，你的手机浏览器就像在敲一扇没有门把手的墙，永远进不去。

你需要去云平台的控制台（如腾讯云、阿里云）找到「安全组」，添加一条入站规则，给对应的端口开绿灯。

这里有两种选择：

**1. 如果你没有域名**
直接放行 **8088 端口**。在手机浏览器输入 `http://你的服务器IP:8088` 就能用。这法子最快，但建议只在可信网络（比如家里的 WiFi）下临时应急。

**2. 如果你有自己的域名**
这才是最正规的方案。首先，去 Cloudflare 这类 DNS 服务商加一条 A 记录：

- 名称：比如 `file`
- 内容：填写你的服务器 IP
- 代理状态：点亮那朵小云（Proxied）

接着，让 AI 帮你配好 HTTPS，你去安全组里要放行的就是 80 和 443 端口。

浏览器地址栏会亮起让人心安的小绿锁。数据加密传输，不用担心内容裸奔。有了 Cloudflare 的加持，还能顺便白嫖 CDN 加速和防攻击。

## 自由感

其实我平时习惯在飞书里审阅稿件。但 File Browser 填补了这套写作工作流里最隐秘的缝隙：素材流转。

它把原本复杂冰冷的服务器目录，变成了一个随手可及的“储物间”。手机里的任何素材、生成的图片，都不再需要找台电脑做中转。在地铁上或者床头点几下手机，它们就安安静静躺在了服务器里，等待下一步指令。

最重要的改观是，电脑不再是那个必须被拴着的重物。这种随时随地、不被设备捆绑的自由感，才是 OpenClaw 用户该有的样子。
